# StrkPerks demo runbook

The `/demo` page is an explicit simulation. Do not open its fabricated hashes
as explorer evidence or describe it as a network transaction.

For a real network demonstration:

1. Connect a Wallet API 0.10.3+ privacy-capable wallet.
2. Show independently verified addresses for the reviewed current classes.
3. Fund the campaign through a public ERC-20 approval and deposit.
4. Prepare the private claim and copy its exact open-note ID.
5. Have the owner approve the conversion ID, app nullifier, note ID, and expiry.
6. Submit the same prepared claim and show the wallet-returned transaction hash.
7. Wait for confirmation and show wallet discovery of the actual note.
8. Show one changed-note rejection and one replay rejection.
9. Explain public metadata versus hidden ownership using `docs/privacy-model.md`.

Never display or record the raw claim secret during the demo.
